Getting Started
===============

New to encrypted backups or the command line? Start here. Each page introduces
one task, with short examples and links to more detail when you need it.

Start with the introduction, or try the Quickstart with a fake note.
Backup and restore writes currently need Linux or macOS; native Windows supports
key creation, verification and previews. See :doc:`../PLATFORMS`.
